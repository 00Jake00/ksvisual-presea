# KSVisual × Presea Rooftop

Sitio estático listo para subirse a GitHub Pages.

## Publicación rápida en GitHub Pages
1. Crear repositorio nuevo.
2. Subir todos los archivos de esta carpeta.
3. Ir a **Settings > Pages**.
4. Elegir **Deploy from branch**.
5. Seleccionar **main** y **/root**.
6. Guardar y esperar el enlace público.

## Estructura
- `index.html`: portada de propuesta.
- `instagram.html`: simulación de perfil/feed.
- `tiktok.html`: simulación de canal TikTok.
- `facebook.html`: simulación de página y eventos.
- `crm.html`: embudo comercial / CRM.

## Nota
Si luego quieren publicarlo en Firebase o Netlify, el sitio ya está listo porque no depende de backend.
